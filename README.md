# C++ Lexical Scanner

A C++ lexical scanner implemented as a Visual Studio project.

## Build

Open `scanner.sln` in Visual Studio, select a supported configuration, and build the solution. The sample input file `hola.txt` is included in the project.

## Project files

- `main.cpp`: program entry point
- `scanner.cpp` and `scanner.h`: scanner implementation
- `hola.txt`: sample input
